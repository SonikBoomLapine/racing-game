# Гоночная игра «Пилот»

Браузерная аркадная игра с видом сверху. Управляй машиной, проходи контрольные точки по порядку и заверши три круга.

## Запуск

Открой index.html в любом современном браузере. Установка и веб-сервер не нужны.

## Управление

- W или стрелка вверх — газ
- S или стрелка вниз — тормоз и задний ход
- A / D или стрелки влево / вправо — поворот
- На телефоне используй экранные кнопки под трассой

На траве машина замедляется.
